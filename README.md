# ColorOS 17 主题工坊

一个在本地跑的第三方主题生成器：以真实 ColorOS 17 主题为骨架，改配色、换壁纸、换图标，重新打包成可直接安装的 `.theme`。

## 启动

双击 `启动工坊.bat`，或在命令行执行：

```bash
python server.py            # 默认 http://127.0.0.1:8765
python server.py --port 8899
```

浏览器会自动打开。只依赖 Python 3.10+ 与 Pillow。

## 目录

```
themelib/core.py        主题解析 / 配色变换 / 壁纸与图标处理 / 界面资源替换 / 打包
server.py               本地 HTTP 服务与 JSON API
tools/extract_theme.py  主题解析导出器(把一个 .theme 完整拆开 + 出报告)
web/                    前端单页应用
templates/              模板库(.theme 放这里就会被识别)
output/                 生成的 .theme 输出目录
exports/                解析导出结果
work/                   上传缓存与临时文件
```

## 解析任意主题

```bash
python tools/extract_theme.py "D:/path/主题.theme"
python tools/extract_theme.py "路径.theme" --out exports/自定义名字
```

输出：

```
exports/<主题名>/
  themeInfo.xml          元信息
  packages/<包名>/       各子包按原路径解开（813 个文件）
  picture/               顶层平铺的预览图
  manifest.json          结构化清单：包 / 文件 / 尺寸 / 颜色
  report.html            可浏览的资源报告（缩略图 + 搜索 + 配色表）
```

报告里会列出：每个包的文件数、图片尺寸与体积、`.9` 与 `webp` 标记、序列帧自动折叠（指纹动画这类一次 30 张的）、去重后的配色表，以及包声明与实际是否一致。

## 六个步骤

1. **选择模板** — 以真实主题为骨架，导入新的 `.theme` 也能当模板
2. **配色方案** — 锚点色映射，保留明暗层次，黑白灰不受影响
3. **壁纸** — 桌面 / 锁屏分开，支持裁剪铺满与模糊补边，可从壁纸取色
4. **图标** — 批量导入（文件名即包名）、单个替换/新增/移除，改形状、缩放
5. **界面资源** — 设置背景、音量面板、关于本机大图、控制中心卡片等
6. **信息 / 导出** — 元信息、全局主题开关、UUID、打包下载

预览区有九个视图，按真机截图 1:1 还原（250×542，对应 1080×2340），字体用 MiSans：

| 视图 | 对应真机界面 | 绑定的主题资源 |
|---|---|---|
| 桌面 | 时钟、图标网格、底部搜索条 | 壁纸、图标 |
| 锁屏 | 日期 / 大时钟 / 运营商 | 锁屏壁纸 |
| 控制中心 | 智慧建议胶囊、磁贴、音乐卡、竖直亮度与音量、圆形开关 | 模糊壁纸、磁贴着色 |
| 音量 | 四条竖直音量条 + 「系统音量」标签 | `systemui_panel_volume_bg.9.png`（C16 叫 `systemui_icon_volume_bg.9.png`，已做别名） |
| 通知 | 三条圆形工具按钮、通知列表、底部胶囊 + FAB | 模糊壁纸 |
| 设置 | 大标题、搜索胶囊、账号卡、无卡片分组列表 | `coui_window_background_selector.9.png` |
| 短信 | 会话列表 | 同设置背景（mms 包同名文件，联动） |
| 电话 | 全部/未接胶囊、通话列表、弹出数字键盘、双卡呼叫 | `pb_bg_dialer.9.png` |
| 关于本机 | 返回导航、MIKU 大图卡片、半透明信息列表、彩色存储条 | `about_device_top_video_last_frame_17.png` |

换任一资源，对应视图会立刻更新——改设置背景时短信页也会同步变（同一个文件）。替换成功后预览会自动跳到那个界面。

模板缺某个资源时该页退回渐变或浅色底，不会白屏。


## 图标管理

**批量导入**：点「选择一批图标」，多选或者直接把文件夹拖进来。文件名就是包名：

```
com.alicloud.databox.png     → 新建图标 + 自动写入 allApps.xml 映射
com.tencent.mm.png           → 模板里已有，直接替换
```

自动识别逻辑：模板里存在同名图标的走替换，不存在的走新增；新增时把文件名去掉 `.png` 当作应用包名写进桌面映射表，不需要手填。

一次导入几百个也没问题——前端按 20 个一批上传，后端 `/api/upload_batch` 批量落盘。

**单个操作**：

| 操作 | 方式 | 效果 |
|---|---|---|
| 替换 | 点图标 | 换图 |
| 移除 | 右上角 × | 打包时从 icons 包删掉该文件并清理映射，系统回落到默认图标 |
| 恢复 | 再点 × | 撤掉移除标记 |
| 撤销 | 左下角 ↺ | 还原成模板原图 |
| 删除 | 新增的图标点 × | 直接从列表移除 |

搜索框同时匹配应用中文名、包名和文件名。卡片右上角标着原始尺寸（模板通常是 168×168），下方状态角标分别是「改」「新」「移除」。

## 界面资源（第 5 步）

会列出主题里全部可替换的图片（除图标和壁纸），每张都标注原始尺寸。几个关键位置：

| 文件 | 尺寸 | 位置 |
|---|---|---|
| `coui_window_background_selector.9.png` | 2160×4800 | 设置 / 联系人 / 短信 / 通话 / 全局，共 5 个包各一份 |
| `systemui_panel_volume_bg.9.png` | 1080×1080 | 音量面板 |
| `about_device_top_video_last_frame_17.png` | 984×702 | 关于本机顶部大图（原版是 ColorOS 字样） |
| `about_device_top_video_mask.png` | 984×702 | 与上一张配套的遮罩 |
| `status_bar_qs_media_bg_active.png` | 415×415 | 控制中心媒体卡 |
| `pb_bg_dialer.9.png` | 950×869 | 拨号盘背景 |

**同名资源默认联动替换**：设置背景在 5 个包里各有一份，只改一处会导致设置和短信背景不一致，所以按文件名同步。列表里同名资源只显示一条，标注「联动 N 个包」。

### .9.png 是怎么处理的

九宫格拉伸标记画在图片最外 1px 的边框上（黑线），直接缩放会把标记洗掉，导致页面拉伸错位。
引擎的做法是：新图缩放进「去掉 1px 边框」的内容区，再把原图的四条边框像素原样贴回去，拉伸行为完全不变。

### 大图压缩

背景类图片是照片时会非常大（2160×4800 无损 PNG 约 8MB，五份就是 40MB）。
开启「大图压缩」后会降到 256 色（`FASTOCTREE`），体积减半以上，框线和九宫格标记单独保留，不受影响。

## 商店预览图

主题商店里展示的那几张效果图，支持增删改：

| 操作 | 方式 |
|---|---|
| 改 | 点有图的卡片换图 |
| 删 | 悬停右上角 × —— 打包时该文件不会写进包里 |
| 增 | 点空槽位（＋点击添加）补齐标准槽位；或「再加一张」自定义命名 |

标准槽位按 ColorOS 规范是 `preview_lock` / `menu` / `play` / `third` 四张，尺寸取模板原图（初音是 1080×2520 竖版双屏）。

自定义命名的预览图（`preview_extra1.png` 这种）写进包里没问题，但主题商店**只认那四个标准名**，多出来的不会显示——适合先放着备用。

模板里一张预览图都没有时，新增会按 2520×1080 生成。

## 主题包结构（逆向自 ColorOS 17 实机主题）

`.theme` 本身是一个 ZIP：

```
themeInfo.xml        作者、名称、UUID/PackageName、版本、子包清单
assets               全局配置子包(assets/colors.xml、colors.xml)
framework-res        全局配色子包
com.android.systemui 状态栏 / 通知 / 控制中心
com.android.settings 设置
com.android.launcher 桌面(图标蒙版 new_iphone_style_mask.png、Scale 缩放)
com.android.xxx_003  某个应用,文件名规则「包名_版本号」
icons                allApps.xml 图标映射 + res/drawable-xxhdpi/*.png
wallpaper            oppo_default_wallpaper.jpg + oppo_default_keyguard_wallpaper.png
picture/res/...      themeInfo.xml 里声明的商店预览图
```

每个子包同样是 ZIP，内部用 `assets/colors.xml` 覆盖系统颜色资源（`<color name="x">#AARRGGBB</color>`），用 `res/drawable-xxhdpi/*` 覆盖图片资源。

## 配色是怎么换的

不是把几十个色值粗暴替换成同一个颜色，而是：

1. 统计所有子包 `colors.xml` 里出现次数最多的「强调色」作为锚点（初音主题里是 `#FF42D4E4`）；
2. 计算锚点与目标色的色相差 ΔH、饱和度比例；
3. 对每个非中性色做 `H += ΔH`、`S ×= 比例`、`L` 按锚点衰减曲线微调。

结果是：锚点色精确变成你选的颜色，浅色渐变、半透明遮罩、深色底都会跟着走，白色/黑色/灰阶保持不动。

### 白灰系主题改不动颜色？

有些模板（比如辉夜 C16）整张配色表都是白、黑、半透明白，饱和度全在 10% 以下，默认的「保护灰阶」会把它们全部跳过——看起来就像"改不了"。

打开 **浅色也染色** 开关即可：饱和度低但明度高的颜色（白、浅灰）会被染成目标色相的淡色版本，深灰和黑仍然保持不动。实测辉夜模板：关闭时改 6/15 个色值，打开后 12/15。

色板区标题会显示「影响 N 处」，N 是 0 就说明这套模板的配色确实跟主色无关。

## 出包后怎么装

1. 把 `.theme` 传到手机；
2. 用「文件管理」打开，选择用「主题商店」导入；
3. 主题商店 → 我的 → 主题 → 应用；
4. 部分机型需要先在主题商店设置里关闭「主题安全校验」。

## 注意

- 模板必须来自真实可用的 ColorOS 17 主题，否则结构对不上；
- 图标形状靠替换桌面蒙版实现，个别机型要重启桌面或重新应用主题才生效；
- 请只使用你有权使用的素材。

## 模板本身的已知情况（初音未来 C17）

- `themeInfo.xml` 声明了 30 个包，实际只有 18 个子包：`lockscreen`、`com.coloros.alarmclock`、`com.tencent.mm` 等 12 个是空声明，所以锁屏时钟、微信皮肤并没有被改；
- `com.android.contacts` 和 `com.android.incallui` 的 21 张图完全一样，是作者复制过去的；
- 没有深色模式专用配色（无 night 资源），深色下会回落到系统默认色；
- 不含字体、铃声、开机动画；
- 分辨率声明是 1920×1080 / 960×540，但资源实际按 1080×2400（2x）制作。
